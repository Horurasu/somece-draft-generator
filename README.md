# somece-draft-generator
Design documentation and complementary materials for the SOMECE Draft Generator: a reflective AI writing tool.

This repository contains the design documentation and supplementary materials for the **SOMECE Draft Generator**, 
a reflective writing tool that frames generative AI as a *mirror* rather than a *typewriter*.

## About

The Draft Generator is an instructional design artifact that structures the author–AI relationship 
to preserve authorship, judgment, and critical thinking in academic writing. 
It does not embed an AI model; instead, it scaffolds the writing process through:

- A nine-step reflective itinerary
- Mandatory prior writing before AI prompting
- Feedback-oriented prompt generation
- A self-regulation checklist with a visual level indicator
